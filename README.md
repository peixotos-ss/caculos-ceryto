# CALCULOS

Crie um jogo completo da cobrinha (Snake Game) utilizando HTML, CSS e JavaScript separados em três arquivos (index.html, style.css e script.js).

O jogo deve atender aos seguintes requisitos:

Interface moderna e bonita, com a tela centralizada (600px de altura e 400px de largura)
Layout utilizando CSS Grid ou Flexbox
Fundo escuro com elementos em cores vibrantes (estilo gamer)
A cobrinha deve crescer ao comer a comida
Movimentação suave utilizando as teclas do teclado (setas ↑ ↓ ← →)
Sistema de pontuação visível na tela
A comida deve aparecer em posições aleatórias dentro do grid
O jogo deve terminar ao colidir com a parede ou com o próprio corpo
Exibir mensagem de "Game Over" com opção de reiniciar
Velocidade da cobrinha aumentando conforme a pontuação
Código bem organizado, comentado e de fácil entendimento
